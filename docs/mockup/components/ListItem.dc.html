Row 1: name (ellipsis), gray property chips such as category or level, a gold cost chip (a coin icon, read aloud as "Cost 15 gp") where the item has a price, a flex spacer, then remove (an x) at the far right.
Row 2: a truncated one-line description.
Row 3: the accent action chips, a flex spacer, then the row's controls at the far right: a 1h/2h grip toggle for a versatile weapon, an Equip toggle, Prepared, Edit, or a feature's use pips. Equip is an 18px icon square, a backpack when stowed and the item type's icon on the accent when equipped. Remove and Edit are gray icons with no border or fill in the same 18px box, so all three line up, each a 12px Lucide icon. A row with no action chips or controls has no third line.
